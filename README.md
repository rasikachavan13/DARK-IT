# 🎃 DARK-IT — Bring Dead Repositories Back to Life

**Your GitHub repository investigator. Find the bugs, uncover the evidence, and revive abandoned codebases.**

Live Demo: https://dark-it.onrender.com/

DARK-IT is an AI-powered GitHub repository investigation tool designed to help developers understand, investigate, and revive codebases. It explores repository activity, identifies potential issues, answers questions about code, and helps developers understand what needs attention.

Because sometimes, your repository isn't dead. It's just haunted. 👻

---

## ✨ Features

### 🔍 Repository Investigation
- Investigate GitHub repositories.
- Explore repository metadata and activity.
- Examine commits, branches, README files, and source code.
- Understand the overall state of a codebase.

### ⚰️ Bug Cemetery
- Identify potential bugs and suspicious code patterns.
- Organize issues discovered during repository investigation.
- Help developers understand areas that need attention.

### 🧾 Evidence Wall
- Present supporting code and repository evidence.
- Make investigation findings easier to understand.
- Connect observations with relevant repository information.

### 👻 Ghost Q&A
- Ask questions about a repository.
- Get AI-assisted explanations of code and project structure.
- Understand unfamiliar codebases more easily.

### 🔥 Repository Roast
- Get an entertaining assessment of your repository.
- Discover potential weaknesses and areas for improvement.

### 🪄 Revival Plan
- Generate actionable suggestions for improving a repository.
- Identify areas that deserve immediate attention.
- Turn investigation findings into practical next steps.

### 🏆 Gamification
- Earn XP and achievements while investigating repositories.
- Make repository exploration more engaging.

## 🚀 Getting Started

### Prerequisites

Make sure you have installed:

- Node.js
- npm
- Git
- A GitHub account
- An API key for the AI provider configured in your backend

### 1. Clone the repository

```bash
git clone https://github.com/rasikachavan13/DARK-IT.git
```

### 2. Navigate to the project

```bash
cd DARK-IT
```

### 3. Install dependencies

```bash
npm install
```

If dependency resolution fails, try:

```bash
npm install --legacy-peer-deps
```

### 4. Configure environment variables

Create a `.env` file in the project root using `.env.example` as a reference.

Add the environment variables required by your configured AI provider.

**Important:** Never commit your actual API keys or secrets to GitHub.

### 5. Start the development server

```bash
npm run dev
```

### 6. Build for production

```bash
npm run build
```

---

## ⚙️ Environment Configuration

The backend requires an AI API key to enable AI-powered features.

Configure the required environment variables in your local `.env` file and your deployment provider's environment settings.

Keep `.env` private. Commit only `.env.example` with placeholder values.

5. Deploy the application.
6. Test repository investigation and AI-powered features.
